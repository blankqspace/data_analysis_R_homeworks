## Final project: Argument Omission in Na’vi and its Explication in English Translation
Данный проект представляет собой количественный и качественный анализ частоты опущения аргументов глагольных предикатов в искусственном языке На’ви (из франшизы «Аватар») по сравнению с их официальными английскими переводами. Исследование направлено на выявление типологических различий между агглютинативным языком На’ви, допускающим про-дроп (pro-drop), и аналитическим английским языком, требующим обязательного синтаксического наличия подлежащего и дополнения.

### Данные 
Используется параллельный корпус из 101 наблюдения (аргумента), взятого из фильмов франшизы «Аватар», официальных субтитров и материалов Пола Фроммера. 

### Используемые инструменты 
Проект реализован в среде R с помощью пакетов dplyr, ggplot2, tidyr и статистических тестов mcnemar.test, fisher.test

### Ключевые результаты
1) Сравнение языков (Гипотеза 1 подтверждена)
- В На’ви доля опущений составляет ~13%, в английском доля опущений составляет ~2%
- Тест Макнемара показал значимое различие (p = 0.0098 < 0.05)

2) Анализ по семантическим ролям (Гипотеза 2 не подтверждена статистически)
- Визуально агенсы опускаются чаще (17%) чем пациенсы (6%), что противоречит исходному ожиданию
-  Тест Фишера показал p=0.2099>0.05. Различие не является статистически значимым из-за малого объема выборки
